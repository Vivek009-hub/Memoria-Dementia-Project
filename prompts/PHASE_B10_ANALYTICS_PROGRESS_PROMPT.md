# Memora - Phase B10 Prompt: Analytics & Progress Tracking

**Phase:** B10  
**Name:** Analytics, Cognitive Progress & Activity Tracking  
**Prerequisites:** B0-B9 completed  
**Status:** Ready for implementation

---

# Objective

Implement Memora's backend analytics and progress-tracking system.

B10 creates a centralized analytics layer that transforms activity generated by previous modules into useful, privacy-conscious progress data.

The system should track and analyze:

```text
Cognitive game performance
Memory assistance usage
Reminder adherence
Community participation
Meeting attendance
General engagement
Patient progress over time
```

The architecture should distinguish between:

```text
Raw Activity
      ↓
Analytics Events
      ↓
Aggregation
      ↓
Progress Metrics
      ↓
Authorized Dashboard APIs
```

B10 is backend only.

Do NOT build the frontend dashboard in this phase.

# 3. IMPORTANT SAFETY PRINCIPLE

Memora analytics are for:

```text
Activity tracking
Progress visualization
Engagement monitoring
Reminder adherence
Game performance
Session participation
```

They are NOT:

```text
Medical diagnosis
Clinical diagnosis
Dementia severity diagnosis
Treatment recommendations
Medication recommendations
Medical decision making
```

Never label an analytics metric as a medical diagnosis.

Avoid statements such as:

```text
"Dementia is getting worse."
"Patient has declined cognitively."
"Patient should change treatment."
```

Prefer:

```text
"Game accuracy decreased over the last 7 sessions."
"Reminder completion rate was 82% this week."
"Community participation increased this month."
```
