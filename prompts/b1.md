# 2. USER MODEL

Create:

```text
server/src/modules/users/
```

Create an appropriate User model.

Fields:

```text
name
email
passwordHash
role
profileImageUrl
preferredLanguage
isActive
lastLoginAt
createdAt
updatedAt
```

Roles:

```text
PATIENT
CAREGIVER
ADMIN
HOST
```

Requirements:

* Use Mongoose.
* Use timestamps.
* Email must be required.
* Email must be normalized.
* Email must be unique.
* Email must be indexed appropriately.
* Role must use controlled enum values.
* `isActive` should have an appropriate default.
* Do not store plaintext passwords.
* Do not implement authentication.
* Do not implement password hashing.
* Do not expose passwordHash through future default queries unnecessarily.

Do not add fields not specified by the database specification unless clearly justified.
