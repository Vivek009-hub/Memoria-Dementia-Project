# 🧠 Memora

> **An AI-Powered Cognitive Care, Memory Assistance, Community and Safety Platform for Dementia Patients.**

Memora is a comprehensive digital platform designed to support people living with dementia through cognitive stimulation, memory assistance, personalized reminders, AI-powered interaction, community engagement, caregiver support, and personal safety monitoring.

The platform focuses on creating a **simple, accessible, and supportive digital experience** for patients while providing caregivers and administrators with the tools required to manage care, engagement, and safety.

---

# 🌟 Vision

Memora aims to make technology more accessible and useful for people living with cognitive challenges.

The platform brings together:

* 🧠 Cognitive stimulation
* 🎮 Personalized cognitive games
* 🖼️ Memory assistance
* 🔔 Smart reminders
* 🎙️ AI-powered voice interaction
* 🌐 Regional language support
* 🫂 Community engagement
* 🟣 Memora Meeting Circle
* 👨‍👩‍👧 Caregiver support
* 📍 Location monitoring
* 🏠 Geofencing
* 🆘 SOS alerts
* 🤕 Possible fall detection

into one integrated ecosystem.

---

# ⚠️ Important Disclaimer

Memora is a **support and assistance platform**.

It is **not a medical diagnostic system** and does not:

* Diagnose dementia
* Cure dementia
* Replace doctors or healthcare professionals
* Provide medical treatment decisions
* Guarantee fall detection
* Guarantee emergency response

All cognitive, engagement, and safety-related information should be treated as supportive information and not as professional medical advice.

---

# 🎯 Key Objectives

Memora is designed to:

* Support daily independence for dementia patients.
* Provide simple cognitive stimulation activities.
* Help patients remember important people, places, events, and information.
* Provide reminders for daily activities and important events.
* Enable simple AI and voice-based interaction.
* Reduce complex navigation through a simplified user interface.
* Encourage social interaction and community participation.
* Provide caregivers with tools to support authorized patients.
* Provide optional safety monitoring through a companion mobile application.

# 🫂 Community Sessions

Memora Community Sessions provide structured social and engagement activities.

The Community Sessions feature contains two primary sections:

## 🗳️ Vote

Admins create proposed session ideas.

Patients can vote for sessions they are interested in.

Example:

### 🎵 Music & Memory

Share memories connected to songs, music, and important moments.

👥 Interested: 42 patients

🗳️ **Vote for this Session**

Other examples include:

* 📖 Story Sharing Circle
* 🎨 Art & Memory
* 🎵 Music & Memory

### Voting Flow

```text
Admin creates session proposal
            ↓
Patients view proposals
            ↓
Patients vote
            ↓
Admin reviews results
            ↓
Admin approves or rejects
```

Once approved, a proposal can be scheduled as an official event.

---

# 📅 Schedule

The Schedule section contains officially approved events.

Administrators can configure:

* 📅 Date
* ⏰ Time
* ⏳ Duration
* 🎙️ Host
* 👤 Featured guest
* 🖼️ Guest image
* 📝 Description
* 👥 Maximum participants
* 🎥 Voice or Video mode
* 📝 Registration status

Patients can:

* View scheduled sessions
* Pre-register
* Cancel registration
* Join a waiting list if enabled

### Community Session Flow

```text
Admin creates proposal
        ↓
Patients vote
        ↓
Admin reviews results
        ↓
Admin approves proposal
        ↓
Admin schedules event
        ↓
Event appears in Schedule
        ↓
Patients pre-register
        ↓
Memora sends reminders
        ↓
Community Session takes place
```

Patients who voted for an approved session can receive notifications when it becomes available for registration.

# 🏠 Geofencing

Caregivers can configure safe zones.

Example:

```text
       ┌─────────────────────┐
       │                     │
       │      SAFE ZONE      │
       │                     │
       │        👴           │
       │                     │
       └─────────────────────┘
                  ↓
          Patient exits zone
                  ↓
              🚨 Alert
```

The system can track:

* Geofence entry
* Geofence exit
* Timestamp
* Relevant location

Authorized caregivers can receive alerts when a configured safety event occurs.

# 🆘 SOS Emergency System

The mobile application includes a prominent SOS feature.

```text
Patient activates SOS
        ↓
Confirmation
        ↓
SOS activated
        ↓
Latest available location retrieved
        ↓
Authorized caregiver notified
        ↓
Safety event recorded
```

Possible SOS states:

* Initiated
* Confirmed
* Cancelled
* Acknowledged
* Resolved

---

# 🤕 Possible Fall Detection

The mobile application may use smartphone sensors such as:

* Accelerometer
* Gyroscope
* Device orientation

Conceptual flow:

```text
Sensor activity
       ↓
Possible fall detected
       ↓
"Are you okay?"
       ↓
   ┌───┴───┐
   ↓       ↓
  OK      HELP
   ↓       ↓
Cancel    Alert caregiver
```

If no response is received within a configured time period, the system may notify an authorized caregiver.

> This feature provides possible-fall detection and does not guarantee detection of every fall.

# 🤖 AI-Assisted Development

Memora is being developed using AI coding assistants.

Every AI coding assistant must follow the project's documented architecture and rules.

Before implementing a feature, the AI assistant should inspect:

```text
PROJECT_SPEC.md
CLAUDE.md
docs/ARCHITECTURE.md
docs/DATABASE.md
```

## Rules for AI-Generated Code

AI coding assistants must:

* Inspect existing code before creating new code.
* Follow existing architecture.
* Avoid duplicate models and APIs.
* Avoid unnecessary dependencies.
* Follow naming conventions.
* Never expose API keys or secrets.
* Keep business logic on the backend.
* Add validation.
* Add tests where appropriate.
* Avoid modifying unrelated modules.
* Report assumptions instead of silently changing requirements.

AI coding assistants must not independently redefine Memora's product requirements.

# 🌿 Git Workflow

The `main` branch is protected and should remain stable.

Feature development should use dedicated branches.

Example:

```text
main
│
└── develop
     │
     ├── feature/authentication
     ├── feature/patient-management
     ├── feature/cognitive-games
     ├── feature/community-voting
     ├── feature/reminders
     └── feature/mobile-safety
```

Recommended workflow:

```text
Create Issue
      ↓
Create Feature Branch
      ↓
Implement Feature
      ↓
Run Tests
      ↓
Push Branch
      ↓
Create Pull Request
      ↓
Code Review
      ↓
CI Checks
      ↓
Merge
```

No developer should directly push experimental work to `main`.

# 🔐 Security Principles

Memora handles sensitive information.

All development must follow:

* Authentication
* Role-based authorization
* Ownership checks
* Input validation
* Password hashing
* Secure API design
* Secure secret management
* Protected location information
* Secure file uploads
* Audit logging where appropriate
* HTTPS in production

### Critical Rule

Authorization must always be enforced on the backend.

Changing a patient ID in a frontend request must never allow a user to access another patient's data.
