# Memoria — Caregiver Connection & Pairing API Specification

**Version:** 1.0  
**Base Path:** `/api/v1`

---

## Endpoint Summary

### 1. Patient Caregiver Management

#### `GET /api/v1/patients/me/caregivers`
- **Auth**: Required (`PATIENT` role)
- **Description**: Returns all caregiver relationships (active and pending) for the authenticated patient.

#### `POST /api/v1/patients/me/caregivers/invite`
- **Auth**: Required (`PATIENT` role)
- **Body**: `{ relationshipType?: "FAMILY"|"PROFESSIONAL"|"GUARDIAN"|"OTHER", caregiverEmail?: string }`
- **Description**: Generates a secure, 6-character pairing code valid for 24 hours.

#### `POST /api/v1/patients/me/caregivers/:relationshipId/accept`
- **Auth**: Required (`PATIENT` role)
- **Description**: Accepts a pending caregiver connection request.

#### `PATCH /api/v1/patients/me/caregivers/:relationshipId/permissions`
- **Auth**: Required (`PATIENT` role)
- **Body**: `{ permissions: { viewProfile: boolean, viewLocation: boolean, manageReminders: boolean, ... } }`
- **Description**: Updates granular data sharing permissions for a specific caregiver.

#### `POST /api/v1/patients/me/caregivers/:relationshipId/revoke`
- **Auth**: Required (`PATIENT` role)
- **Description**: Revokes caregiver relationship (`status: "REVOKED"`).

---

### 2. Caregiver Pairing

#### `POST /api/v1/caregivers/pair`
- **Auth**: Required (`CAREGIVER` role)
- **Body**: `{ inviteCode: "7A8F9B" }`
- **Description**: Redeems a 6-character pairing code generated by a patient, establishing an `ACTIVE` caregiver relationship.

---

### 3. Emergency Contacts CRUD

- `GET /api/v1/patients/me/emergency-contacts`
- `POST /api/v1/patients/me/emergency-contacts`
- `PATCH /api/v1/patients/me/emergency-contacts/:contactId`
- `DELETE /api/v1/patients/me/emergency-contacts/:contactId`
